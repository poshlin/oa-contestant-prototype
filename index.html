01 / 12 THE STRUGGLE 困境

為什麼會寫程式，
卻打不贏每一場 BOSS？

孩子上完基礎程式課之後，往往卡在「會寫但拿不到分」的瓶頸。
差別不在「會不會」，而在於 有沒有人帶、有沒有題目、有沒有實戰。

  1. 01 STRUGGLE
    ✕ BAD ENDING

    獨自刷題沒方向

    花了 100 小時在 zerojudge 隨機刷題，APCS 級分還是 2 級。沒人幫 review，不知道進步在哪裡。

    → TRUE ENDING

    教練帶你練對題型

    每期 15 週循序漸進，每週題目對應檢定時程。教練 code review，每一小時都有累積。

  2. 02 STRUGGLE
    ✕ BAD ENDING

    只會語法不會演算法

    寫得出程式，但 sub-tasks 拿不滿、資料量一大就 TLE。卡在 2-3 級分上不去。

    → TRUE ENDING

    看到題目就知道用哪招

    學會 3 大領域 + 8 項程式核心技巧（資料結構、動態規劃、圖論、樹狀圖等），從 2 推到 5 級分。

  3. 03 STRUGGLE
    ✕ BAD ENDING

    沒實戰經驗 臨場失常

    時間壓力、未知題型、考場環境。平常解得出來，正式 APCS 卻拿不到分。比賽次數太少 = 沒有實戰肌肉記憶，努力與成績脫鉤。

    → TRUE ENDING

    每月參賽養成肌肉記憶

    兩個月一次小比賽、每期 15 堂內一次大比賽。真實上場累積履歷與心理素質。每場賽後教練帶選手檢討，把失分轉成下次的進步。

11 / 12 THE TRUTH 表象與真相

這不是刷題班，
是解題思維訓練。

從外表看，孩子好像是在一直解題。
但實際上真正在訓練的，是分析、演算法選擇、複雜度判斷、code review。

解 zerojudge 100 題
→
看到題目就知道用哪種演算法
背遞迴 / 排序的寫法
→
什麼題目該用遞迴或排序
知道答案後對著抄
→
自己拆題目、設計演算法、優化效能
程式跑得出來就好
→
用 Big-O 估算複雜度、避免 TLE
自己一個人 debug
→
用 IDE / Debugger，有教練 review
考完忘了不會記錄
→
寫 HackMD 解題文章，累積升學歷程
真正的學習目標，不是孩子解過多少題；
而是在競賽當下能選對演算法、寫出能拿分的程式。

// MISSION FILE · v15 15 entries · classified by topic
  1. FILE.01 橘蘋選手班是什麼？ +
    橘蘋選手班是橘蘋為「已具備程式基礎、想進階參賽的孩子」設計的 競賽培訓專班。課程涵蓋資料結構、演算法、程式效能、解題策略與全年競賽實戰，目標是讓孩子在 APCS、CPE、TOI、NPSC 等檢定競賽中真正拿到分數、累積升學履歷。
  2. FILE.02 選手班只是 APCS 衝刺班嗎？ +
    不只是。APCS 是檢定，選手班的訓練範圍更廣：除了 APCS 觀念 + 實作之外，還包含 CPE、ITSA、TOI、NPSC、ISSC、資訊學科能力競賽等多項全年競賽。重點是讓孩子建立扎實的演算法基礎與解題思維，這套能力面對任何程式競賽都通用。
  3. FILE.03 跟一般程式班 / APCS 培訓班差在哪？ +
    一般程式班教孩子「會寫程式」，APCS 培訓班是「準備 APCS 一場檢定」。選手班是更高階的長期訓練：差異化分級 + 全年競賽路徑 + 教練 code review + 解題文章撰寫 + 2 次補課保證，目標是讓孩子 從 APCS 2 級分推到 5 級分、進入資科系所。
  4. FILE.04 誰會是我孩子的授課老師？是綠茶老師親自教嗎？ +
    視梯次而定，誠實揭露：
    ① 週五晚上班 — 由綠茶總教練親自帶班，這個班別已持續多年。
    ② 其他新時段班（如週六） — 由綠茶總教練培訓認證的教練群授課。所有教練皆通過綠茶總教練的培訓、採用同一套教材、同一套 code review 方法，並由綠茶總教練持續督導教學品質。
    報名前，專員會與您確認您想要的時段、實際授課教練的背景資料。
  5. FILE.05 沒參加過競賽，可以上嗎？ +
    可以，只要 有基本程式基礎（APCS 2 級分以上、或修畢橘蘋 APCS 培訓班 / 進階班）。沒有競賽經驗反而是常態 — 選手班會循序帶孩子從小比賽（線上練習賽）開始，再進階到大比賽。
  6. FILE.06 幾年級適合？需要什麼基礎？ +
    建議 7 年級（國中一年級）以上。並需符合任一基礎條件：① APCS 實作題 2 級分以上（100 分以上）、② 修畢橘蘋 APCS 培訓班 / 培訓營 / 進階班、③ 對程式解題與競賽有強烈興趣，具自主學習能力（檢具其他程式能力證明，人工審核）。
  7. FILE.07 需要準備什麼設備？為什麼不能用平板？ +
    設備建議：
    ✓ 筆電：最理想，內建鏡頭與麥克風可直接上課
    ✓ 桌電：可以，但需額外準備 耳機與麥克風
    ✕ 平板、平板加鍵盤、手機：不可以

    原因：課程中需要進行多種解題操作、code review、檔案管理，加上要與老師即時互動討論，需要鍵盤輸入、滑鼠操作、檔案管理與穩定麥克風，平板難以勝任這些需求。
  8. FILE.08 一期 15 堂下來，孩子會累積什麼成果？ +
    一期下來會累積：① 至少 1 次大比賽 / 檢定參賽紀錄、② 至少 3-5 次小比賽（線上練習賽）、③ 完整的 HackMD 解題文章作品集（升學履歷加分）、④ 系統性的演算法與資料結構基礎。
  9. FILE.09 課程強度會不會太硬？孩子吃得消嗎？ +
    選手班強度確實高於一般程式課，但採 差異化分級（初級 / 成長級 / 進階級），每位學生會拿到適合自己程度的題目。第一堂的能力測驗就是為了精準評估強度配置。不會吃力到放棄、也不會輕鬆到沒進步，這是橘蘋的設計重點。
  10. FILE.10 一定要參加競賽嗎？只是想學演算法可以嗎？ +
    是的，需要參賽。選手班的設計理念是「真實上場才會真正進步」，所以要求：① 兩個月內至少參加一次 小比賽、② 15 堂課內至少要有一次 大比賽或檢定。連續三個月未參賽會建議退出。如果只想學演算法、不想參賽，建議改選一般程式進階班。
  11. FILE.11 上課方式是講課還是練題？比例大概多少？ +
    每堂 2 小時的分配：講師授課 + 解題實作 + code review + HackMD 文章撰寫。前半段為演算法主題講解 + 例題分析，後半段為孩子自己解題 + 老師 code review + 同學互相討論。每堂課後要撰寫 解題文章記錄思路。
  12. FILE.12 缺課可以補課嗎？課程進度怎麼安排？ +
    提供 2 次完整補課機會。每期 15 週為 1 個訓練週期：
    ① 請假 1 次 → 該期自動順延 1 週（變 16 週）
    ② 請假 2 次 → 該期自動順延 2 週（變 17 週）
    這樣設計是為了確保每位選手都能完整跟上進度，不讓任何一堂課白白消失。若超過 2 次缺課或有特殊狀況，請與班主任聯繫討論個別安排。
  13. FILE.13 程式競賽對升學真的有幫助嗎？ +
    非常有幫助，特別對申請資訊學群：① APCS 級分是多數資科系特殊選材的入門檻、② 競賽參賽紀錄是學習歷程的硬實力證明、③ 解題文章展示思考過程，是申請文件加分項。橘蘋選手班歷屆學員已有錄取 政大資科、北大資科、中原資工、逢甲資工（特殊選材）等實績。
  14. FILE.14 沒有 APCS 經驗，能跟得上嗎？ +
    如果孩子完全沒接觸過 APCS 但有其他程式基礎（Python / C++ 等），可以，課程會從基礎演算法逐步建立。但如果連基礎程式語法都還不熟，建議先上橘蘋的 APCS 培訓班或 Python 課程累積基礎，再來上選手班會更有效率。第一堂能力測驗會幫你判斷。
  15. FILE.15 第一堂「能力測驗體驗課」是什麼？要怎麼準備？ +
    選手班的第一堂課不是傳統試聽，是 能力測驗體驗課。流程：① 老師說明選手班的課程目標與規範、② 入班程式解題測驗（引導孩子理解題意 → 實際解題 → 學習教練全程觀察）、③ 測驗結束後進行程式碼檢討、演算法討論、④ 課後撰寫完整評估報告，確認該生是否適合繼續上課。不需要特別準備，帶平常的程式能力來即可。
  16. FILE.16 課程退費規則？ +
    退費依 補習班相關法規計算（依出席堂數比例退還）。例如購買 15 堂課，出席未達第 6 堂前皆可申請退費；超過 1/3 後不再退款。詳細條件可在報名前由專人說明。
